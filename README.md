# 📊 Machine Learning – Regression Projects

## 📌 Project Overview

This repository contains hands-on Machine Learning Regression practice projects using Python. It covers three important regression algorithms: Simple Linear Regression, Multiple Linear Regression, and Gradient Boosting Regressor. The projects focus on data preprocessing, exploratory data analysis, model training, predictions, performance evaluation, and visualization.

## 🎯 Objectives

- Understand fundamental regression techniques.
- Perform data cleaning and preprocessing.
- Explore relationships between independent and dependent variables.
- Train and test machine learning regression models.
- Evaluate model performance using statistical metrics.
- Visualize actual vs. predicted values.
- Identify important features influencing predictions.

## 🧠 Machine Learning Algorithms

### 1. Simple Linear Regression
- Dataset: `study_hours_exam_score.csv`
- Records: 1,000
- Input Feature: `StudyHours`
- Target Variable: `ExamScore`
- Analyze the relationship between study hours and examination scores.
- Calculate slope, intercept, training score, and testing score.
- Visualize the best-fit regression line.

### 2. Multiple Linear Regression
- Dataset: `car_price_multiple.csv`
- Records: 5,000
- Input Features:
  - `EngineSize_L`
  - `Mileage_km`
  - `CarAge_years`
- Target Variable: `Price_USD`
- Predict car prices using multiple independent variables.
- Analyze regression coefficients and feature influence.
- Evaluate predictions using regression metrics.

### 3. Gradient Boosting Regressor
- Dataset: `laptop_price_gbr.csv`
- Records: 10,000
- Input Features:
  - `RAM_GB`
  - `Storage_GB`
  - `ScreenSize_inch`
  - `Weight_kg`
  - `BatteryLife_hrs`
- Target Variable: `Price_USD`
- Implement Gradient Boosting Regression.
- Analyze feature importance.
- Compare actual and predicted prices.
- Understand non-linear relationships in data.

## 📈 Model Evaluation Metrics

The regression models are evaluated using:

- **MAE:** Mean Absolute Error
- **MSE:** Mean Squared Error
- **RMSE:** Root Mean Squared Error
- **R² Score:** Coefficient of Determination

## ⚙️ Model Configuration

Gradient Boosting Regressor parameters:

- `n_estimators = 100`
- `learning_rate = 0.1`
- `max_depth = 3`
- `random_state = 42`

Train-Test Split: 80% Training and 20% Testing.

